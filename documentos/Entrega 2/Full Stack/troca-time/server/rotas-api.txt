API TROCA TICKET - ROTAS
========================

URL base: http://localhost:3000
Formato: JSON. Nenhuma rota recebe body.
Datas: "AAAA-MM-DD HH:MM:SS"
Valores em reais: numero (ex.: 8500)


PADRAO DE ERRO
--------------

{
  "status": number,
  "erro": string
}

400 -> parametro invalido (mensagem da rota)
404 -> recurso nao encontrado (mensagem da rota)
500 -> "Erro interno do servidor"


1) GET /fornecedores/:id
------------------------

Request:
  path   id: integer (> 0, obrigatorio)
  query  -
  body   -

Response 200:
{
  "id": number,
  "nome": string,
  "status_cadastro": string,        // pendente | aprovado | reprovado
  "tipo_usuario": string,           // fornecedor
  "cnpj": string,
  "telefone": string | null,
  "email": string,
  "descricao": string | null,
  "criado_em": string,
  "propostas": [
    {
      "id": number,
      "nome_vaga": string,
      "categoria": string,
      "evento_id": number,
      "nome_evento": string,
      "organizador_id": number,
      "valor": number,
      "status": string,             // enviada | em_negociacao | aceita | recusada
      "descricao": string
    }
  ]
}

Erros:
  400 { "status": 400, "erro": "ID do fornecedor inválido" }
  404 { "status": 404, "erro": "Fornecedor não encontrado" }
  500 { "status": 500, "erro": "Erro interno do servidor" }

5) GET /organizadores/eventos/:id/custos
----------------------------------------

Request:
  path   id: integer (id do evento, obrigatorio)
  query  -
  body   -

Response 200:
{
  "vagas_servico": [
    {
      "id": number,
      "item": string,
      "categoria": string,
      "descricao": string | null,
      "cotacao_ate": string,
      "quantidade_propostas": number,
      "status": string              // pendente | preenchida | vencida
    }
  ],
  "custos": [
    {
      "id": number,
      "descricao": string,
      "tipo": string,               // Fiscal | Operacional | Variável
      "valor": number
    }
  ]
}

Erros:
  400 { "status": 400, "erro": "O ID do evento é obrigatório" }
  500 { "status": 500, "erro": "Erro interno do servidor" }


6) POST /organizadores/eventos/:id/vagas
----------------------------------------

Request:
  path   id: integer (id do evento, obrigatorio)
  query  -
  body
{
  "item": string,                   // obrigatorio
  "categoria": string,              // obrigatorio
  "descricao": string | null,
  "cotacao_ate": string             // obrigatorio, YYYY-MM-DD
}

Response 200:
{
  "vaga_servico_id": number
}

Erros:
  400 { "status": 400, "erro": "O campo <campo> é obrigatório." }
  500 { "status": 500, "erro": "Erro interno do servidor" }


7) POST /organizadores/eventos/:id/custos
-----------------------------------------

Request:
  path   id: integer (id do evento, obrigatorio)
  query  -
  body
{
  "descricao": string,              // obrigatorio

{

}

Erros:
  400 { "status": 400, "erro": "O campo <campo> é obrigatório." }
  500 { "status": 500, "erro": "Erro interno do servidor" }

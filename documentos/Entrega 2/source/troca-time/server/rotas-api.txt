API TROCA TICKET - ROTAS
========================

URL base: http://localhost:3000
Formato: JSON. Nenhuma rota recebe body.
Datas: "AAAA-MM-DD HH:MM:SS"
Valores em reais: numero (ex.: 8500)


PADRAO DE ERRO
--------------

{
  "status": number,
  "erro": string
}

400 -> parametro invalido (mensagem da rota)
404 -> recurso nao encontrado (mensagem da rota)
500 -> "Erro interno do servidor"

========================================================================
DIFERENCIAL: PROPOSTA DIRETA E CHAT (MVP)
========================================================================

Todas as rotas abaixo exigem login (cookie "token").
Status de proposta: pendente | selecionada | aceita | recusada | cancelada
Origem da proposta: fornecedor (enviada pelo fornecedor) | organizador (proposta direta)

Regras:
- Cada proposta é uma conversa entre o organizador do evento e o fornecedor.
- O chat não é em tempo real: o front consulta mensagens novas a cada 5 segundos.
- Só dá para enviar mensagem enquanto a proposta está pendente ou selecionada.
- Proposta direta: só o fornecedor aceita ou recusa; o organizador só cancela (enquanto pendente).
- Quando uma proposta da vaga é aceita, a vaga vira "preenchida". As outras propostas
  abertas da vaga viram "recusada", e as propostas diretas pendentes viram "cancelada".


8) POST /organizadores/propostas  (proposta direta)
---------------------------------------------------
Perfil: organizador

body
{
  "fornecedor_id": number,          // obrigatorio, fornecedor aprovado
  "vaga_servico_id": number,        // obrigatorio, vaga de um evento seu em cotação
  "valor": number,                  // obrigatorio, > 0
  "validade": "AAAA-MM-DD",         // obrigatorio, hoje ou depois
  "descricao": string,              // obrigatorio
  "observacoes": string             // opcional
}

Response 201:
{ "proposta_id": number }

Erros:
  400 campo obrigatório / valor / validade inválidos
  400 { "erro": "Só é possível enviar proposta direta para fornecedores aprovados." }
  400 { "erro": "O evento precisa estar em cotação para enviar proposta direta." }
  403 { "erro": "Esta vaga de serviço não é de um evento seu." }
  404 { "erro": "Fornecedor não encontrado" } | { "erro": "Vaga de serviço não encontrada" }
  409 { "erro": "Esta vaga de serviço já foi preenchida." }
  409 { "erro": "Este fornecedor já tem uma proposta para esta vaga. ..." }


9) GET /organizadores/propostas/vagas_disponiveis?fornecedor_id=:id
-------------------------------------------------------------------
Perfil: organizador
Vagas em aberto dos eventos em cotação do organizador logado, para as quais o
fornecedor ainda não tem proposta. Usada no formulário de proposta direta.

Response 200:
{
  "vagas": [
    { "id": number, "item": string, "categoria": string, "cotacao_ate": string,
      "evento_id": number, "nome_evento": string, "data": string }
  ]
}

Erros:
  400 { "erro": "ID do fornecedor inválido" }


10) PATCH /organizadores/propostas/:id/cancelar
-----------------------------------------------
Perfil: organizador (o que enviou a proposta direta)

Response 200:
{ "id": number, "status": "cancelada" }

Erros:
  400 { "erro": "ID da proposta inválido" }
  403 { "erro": "Só o organizador que enviou a proposta pode cancelá-la" }
  404 { "erro": "Proposta não encontrada" }
  409 { "erro": "Só propostas pendentes podem ser canceladas" }


11) PATCH /fornecedores/propostas/:id/resposta
----------------------------------------------
Perfil: fornecedor (o que recebeu a proposta direta)

body
{ "resposta": "aceita" | "recusada" }

Response 200:
{ "id": number, "status": "aceita" | "recusada" }

Ao aceitar, a vaga vira "preenchida" na hora.

Erros:
  400 { "erro": "A resposta deve ser 'aceita' ou 'recusada'." }
  400 { "erro": "Só propostas diretas do organizador podem ser respondidas pelo fornecedor." }
  403 { "erro": "Esta proposta não foi enviada para você." }
  404 { "erro": "Proposta não encontrada" }
  409 { "erro": "Esta proposta não está mais aguardando resposta." }
  409 { "erro": "O evento não está mais em cotação." }
  409 { "erro": "A validade desta proposta já passou." }
  409 { "erro": "A vaga já foi preenchida por outro fornecedor. A proposta foi cancelada." }


12) GET /conversas
------------------
Perfil: organizador ou fornecedor
Lista as propostas do usuário como conversas, da mais recente para a mais antiga.
Para o fornecedor, "selecionada" aparece como "pendente".

Response 200:
{
  "conversas": [
    {
      "proposta_id": number, "status": string, "origem": string,
      "valor": number, "descricao": string, "observacoes": string | null,
      "validade": string, "vaga_servico_id": number, "item": string,
      "categoria": string, "status_vaga": string,
      "evento_id": number, "nome_evento": string, "data_evento": string,
      "status_evento": string,
      "participante": { "id": number, "nome": string, "tipo": string },
      "ultima_mensagem": string | null, "ultima_mensagem_em": string | null,
      "aberta": boolean               // true = ainda aceita mensagens
    }
  ]
}


13) GET /conversas/:propostaId/mensagens?depois_de=:ultimoId
------------------------------------------------------------
Perfil: participante da conversa
depois_de é opcional (padrão 0): devolve só mensagens com id maior.

Response 200:
{
  "mensagens": [
    { "id": number, "proposta_id": number, "remetente_id": number | null,
      "tipo": "texto" | "sistema", "conteudo": string, "criado_em": string,
      "minha": boolean }
  ]
}

Erros:
  400 { "erro": "ID da proposta inválido" } | { "erro": "Parâmetro depois_de inválido" }
  403 { "erro": "Você não participa desta conversa" }
  404 { "erro": "Proposta não encontrada" }


14) POST /conversas/:propostaId/mensagens
-----------------------------------------
Perfil: participante da conversa
O remetente vem do token, nunca do body.

body
{ "conteudo": string }              // 1 a 1000 caracteres

Response 201: mesma estrutura de uma mensagem do item 13.

Erros:
  400 { "erro": "A mensagem não pode ser vazia" }
  400 { "erro": "A mensagem deve ter no máximo 1000 caracteres" }
  403 { "erro": "Você não participa desta conversa" }
  404 { "erro": "Proposta não encontrada" }
  409 { "erro": "Esta conversa está encerrada" }
